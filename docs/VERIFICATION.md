## Issues found & fixed during verification

1. **AI never reached the model (real bug).** The `X-Title` request header contained
   an em-dash (`—`, U+2014). `fetch` headers must be Latin-1, so every OpenRouter
   call threw before sending and silently fell back to degraded mode. Fixed to ASCII.

2. **`.env` was bundled into the Vercel deployment (security).** Next.js loaded
   `ENABLE_DEV_LOGIN=true` from it at runtime, exposing passwordless dev-login in
   production. Fixed with `.vercelignore` (exclude `.env*`) **and** a hard code guard
   that disables dev-login on any `VERCEL_ENV` production/preview deploy regardless
   of the flag.

## Known limitations (by design / scope)

- **Rate limiting is in-memory** (per serverless instance). Correct for current
  scale; swap `src/lib/rate-limit.ts` for Upstash Redis for multi-region accuracy.
- **Google app is in "Testing" mode** — only added test users can sign in until you
  publish the OAuth consent screen.
- **Lighthouse scores not formally measured** — structure favors high scores but the
  numbers are unverified.
- CSP allows `'unsafe-inline'` for scripts/styles (required by Next's inline
  bootstrap + Tailwind); tighten with nonces if needed.
